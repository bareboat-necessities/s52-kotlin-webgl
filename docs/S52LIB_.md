# s52lib-compatible gallery path

The s52lib-compatible gallery APIs expose browser-friendly views of the loaded
symbol, line, pattern, color, and lookup assets so regressions can be inspected
without invoking a full chart application.

The demo routes include:

```text
#symbols
#lines
#patterns
#colors
#all
#opencpn-symbols
#opencpn-lines
#opencpn-patterns
#opencpn-colors
#opencpn-lookups
#opencpn-regression
#opencpn-diagnostics
```

These galleries are visual/debugging aids for portrayal development. They are
experimental, not type-approved ECDIS output, and not for navigation.
