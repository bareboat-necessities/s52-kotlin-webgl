# ESRI phases 5-7

This increment advances the ESRI/INT1 profile from generated SVG mesh assets into
rule-level and CSP-level portrayal scaffolding.

## Phase ESRI-5 — direct XML rule translation

Adds a generated Kotlin rule registry from `CustomPresentationLibrary/CustomSymbolMap.xml`.
The registry preserves ESRI feature/object, primitive, condition, symbol, function,
and rule-filter information in a common Kotlin model:

- `EsriPortrayalRule`
- `EsriRuleFilter`
- `EsriRuleAction`
- `EsriGeneratedRuleRegistry.kt` generated by `generateEsriDirectRules`

This phase deliberately does not replace the existing OpenCPN lookup engine yet. It
creates the machine-readable ESRI rule surface needed by later integration.

## Phase ESRI-6 — alias closure reports

Adds seed alias tables under `s52/esri/` and a report task that compares OpenCPN
symbol/line/pattern references against:

- generated ESRI SVG vector symbols,
- ESRI direct XML symbol references,
- local alias TSV files.

Generated report:

```text
s52-preslib/build/reports/esri/alias-closure-report.csv
s52-preslib/build/reports/esri/alias-closure-report.json
```

The task is intentionally report-first. Later release phases should make unresolved
items fatal after the alias tables and CSP ports have matured.

## Phase ESRI-7 — high-priority Lua/CSP ports

Adds common Kotlin CSP scaffolding and first-pass ports for high-priority ESRI Lua
procedures:

- `sounding`
- `lights`
- `wrecks05`
- `depare03` / `drgare02`
- `resare04`
- `bridge02`
- `cblohd02`
- `cblsub02`
- `sbdare01` / `sbdare02`
- `lndare01` / `lndelv01`

These ports emit ESRI instructions, not final draw commands. A later adapter will
map these instructions into the existing `S52DrawCommand` stream once the ESRI
profile is plugged into `S52PortrayalSession`.

## Tasks

```bash
gradle :s52-preslib:generateEsriDirectRules -Pesri.sourceDir=/path/to/nautical-chart-symbols
gradle :s52-preslib:checkEsriAliasClosure -Pesri.sourceDir=/path/to/nautical-chart-symbols
gradle :s52-preslib:criticalEsriCheck -Pesri.sourceDir=/path/to/nautical-chart-symbols
```

`criticalEsriCheck` now covers phases ESRI-0 through ESRI-7.
