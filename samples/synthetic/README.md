# Synthetic samples

This directory is reserved for small synthetic feature fixtures used by the demo and golden tests.

The project intentionally does not parse S-57. Synthetic features are normalized `EncFeature` values that exercise the portrayal boundary without requiring chart files.

For copyable examples, see:

- `samples/minimal-api/`
- `samples/transcript/`
- `samples/custom-preslib/`
- `samples/webgl-browser/`
