# Security policy

This project is experimental and not for navigation.

## Supported versions

The repository is pre-1.0. Security and correctness fixes should target `main` until a stable release branch policy exists.

## Reporting issues

Please open a GitHub issue for non-sensitive bugs.

For sensitive security concerns, do not include private chart data, restricted standards assets, credentials, or personal information in public reports. Open a minimal issue first and coordinate a private disclosure path with the maintainers.

## Data boundary

This repository should not require secrets, live vessel data, GPS/NMEA streams, encrypted S-63 chart permits, or proprietary chart assets for its tests. Official Presentation Library source assets should be supplied locally by users only when their redistribution rights are clear.
